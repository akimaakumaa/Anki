# Anki Card Importer

Автоматизация создания и синхронизации карточек в Anki из текстовых файлов.

## Требования

- [Anki](https://apps.ankiweb.net/) с установленным плагином [AnkiConnect](https://ankiweb.net/shared/info/2055492159) (код: `2055492159`)
- Python 3.x
- Anki должен быть **открыт** во время запуска скриптов

---

## Структура папки

```
Anki/
├── add_to_anki.py        # основной скрипт
├── add_to_anki.bat       # запуск импорта (двойной клик)
├── configure_anki.bat    # применить настройки ко всем колодам
├── prompt.md             # промпт для генерации карточек через AI
├── Irregular Verbs.txt   # колода: неправильные глаголы (чанки)
├── Oxford 3000.txt       # колода: слова Oxford 3000
├── 1. i → a → u.txt     # колода: паттерн неправильных глаголов
├── 2. -ew  -own.txt      # колода: паттерн -ew → -ew → -own
└── 3. o + -en suffix.txt # колода: паттерн o + -en суффикс
```

## Как добавить новые карточки

### Шаг 1 — Сгенерировать карточки через AI

Открой `prompt.md`, скопируй промпт в ChatGPT / Claude / Gemini, добавь свои слова в конец и получи готовые карточки в нужном формате.

### Шаг 2 — Создать или обновить файл колоды

Каждый `.txt` файл в папке — это отдельная колода. **Имя файла = название колоды в Anki.**

Примеры:
| Файл | Колода в Anki |
|---|---|
| `Irregular Verbs.txt` | `Irregular Verbs` |
| `Oxford 3000.txt` | `Oxford 3000` |
| `1. i → a → u.txt` | `1. I → A → U` |

Чтобы создать новую колоду — просто создай новый `.txt` файл с нужным названием.

### Шаг 3 — Запустить импорт

Дважды кликни `add_to_anki.bat`. Скрипт:
- найдёт все `.txt` файлы в папке
- создаст колоду в Anki, если её нет
- добавит новые карточки
- обновит изменённые карточки
- пропустит карточки без изменений

## Формат карточки

Каждая карточка в файле пишется в таком формате:

```
FRONT:
1. Первое предложение — контекст А
2. Второе предложение — контекст Б
3. Третье предложение — другой регистр

BACK: [type: verb+noun]
**полная фраза** = краткое определение на английском
Example 1: ...
Example 2: ...
Watch out: распространённая ошибка
Synonyms: синоним 1, синоним 2
```

**Правила:**
- Ключевое слово во Front выделяется `<b>bold</b>`, пропущенное слово заменяется `___`
- Жирный текст в Back пишется через `**двойные звёздочки**` — скрипт сам конвертирует в HTML
- Между карточками обязательна пустая строка (или просто начинай следующую с `FRONT:`)
- Кодировка файла: **UTF-8**

## Настройки колод

Запусти `configure_anki.bat` один раз после установки — применит оптимальные настройки ко всем колодам.

| Параметр | Значение | Почему |
|---|---|---|
| New cards/day | 10 | 300 глубоко усвоенных фраз в месяц без выгорания |
| Max reviews/day | 9999 | Алгоритму виднее, искусственный лимит ломает SRS |
| Learning steps | 1m → 10m → 1d | Фраза «ночует» в голове — консолидация через сон |
| Graduating interval | 3 дня | Оптимальный прыжок для закреплённого чанка |
| Easy interval | 7 дней | |
| Insertion order | Sequential | Карточки идут в хронологическом порядке контекста |
| Relearning steps | 10m | Забыл — вернётся через 10 минут |
| Leech threshold | 4 провала | Стандарт завышен, 4 — достаточно |
| Leech action | Suspend Card | Не трать ресурс на пробивание стены |

> **Важно:** запускай `configure_anki.bat` каждый раз, когда создаёшь новую колоду — настройки применяются только к существующим колодам.

## Частые проблемы

**Скрипт не запускается / ошибка подключения**
→ Убедись, что Anki открыт и плагин AnkiConnect установлен.

**Карточка не обновляется**
→ Скрипт сравнивает поле `Back` по точному тексту. Если изменил `Front` — это считается новой карточкой (старая останется).

**Файл игнорируется**
→ Проверь, что файл не перечислен в `SKIP_FILES` внутри `add_to_anki.py`. По умолчанию игнорируется только `example_cards.txt`.

**Карточка стала «пиявкой» и заморожена**
→ Это нормально. Значит, чанк не откликается. Перепиши карточку и запусти импорт заново — скрипт обновит `Back`.
